; UNSCII: the UNC 64 character ROM, glyphs $00-$7F. Mapped at $D000-$D3FF.
; Codes $80-$FF are drawn as these glyphs in reverse video (chapter 8 of the manual).
;
; This file IS the ROM: unc-core reads it at compile time (src/charset.rs).
; Each glyph: a "$nn name" line, then 8 rows of 8 pixels, top row first.
; "#" is ink, "." is paper. The leftmost pixel is bit 7 of the row byte.
; Text glyphs use columns 0-6 and rows 0-6; column 7 and row 7 are the gap.
