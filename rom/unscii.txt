; UNSCII: the UNC 64 character ROM, glyphs $00-$FF. Mapped at $D000-$D7FF.
;
; $00-$1F  graphics: quarter blocks, lines, corners and shades
; $20-$7F  ASCII: punctuation, digits, capitals, lowercase ($7F is a diamond)
; $80-$FF  the second half, for 256-glyph mode (VMODE bit 0): the pictures (eighth blocks,
;          card suits, a ball, arrows, a face, a note), the same reversed, double lines,
;          letters with accents, more signs, and a few things to play with
;
; Without 256-glyph mode, codes $80-$FF are drawn as glyphs $00-$7F in reverse video
; (chapter 8 of the manual), and the second half isn't used.
;
; This file IS the ROM: unc-core reads it at compile time (src/charset.rs).
; Each glyph: a "$nn name" line, then 8 rows of 8 pixels, top row first.
; "#" is ink, "." is paper. The leftmost pixel is bit 7 of the row byte.
; Text glyphs use columns 0-6 and rows 0-6; column 7 and row 7 are the gap. Lowercase
; letters with tails (g j p q y) use row 7 too.
