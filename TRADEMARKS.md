# The names

The code and the manual are open source. The names aren't part of that: "UNC 64", "UNC 16", "United Northern Computers" and the UNC logo belong to MRR Copilot Oy.

**Fine without asking:**

- Saying your program, tool, port or emulator is "for the UNC 64", "UNC 64 compatible" or "runs UNC 64 programs".
- Writing about the UNC 64, teaching it, streaming it.
- Forking this repository, under a different name.

**Ask first** (unc@viljami.io): naming your own product, emulator or hardware "UNC" anything, using the logo, or selling merchandise with the names on it.

The point is only that people can tell what's the UNC 64 and what's built on it.
