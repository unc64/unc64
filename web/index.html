      The Machine Room

      The UNC 64 in your browser: the real emulator, an assembler, a debugger and a tape deck. Nothing leaves your computer.

      Everything the machine does is in the Programmer's Reference Guide (PDF): UNC BASIC, every register, every instruction and every ROM routine.

      Write and run

      Write assembly (.s) or UNC BASIC (.bas), then Run (Ctrl+Enter). Assembly is assembled and started. BASIC is typed into the machine for you, then RUN. A project can have several files: .include "other.s" reads another one. The file marked MAIN is the one that runs.

      Keys

      Click the screen and your keys go to the machine: the cursor keys, RETURN, DELETE (Backspace), INSERT (Insert, or Shift+Backspace), Ctrl+C for STOP, and Page Up for RESTORE (Shift+Page Up is STOP and RESTORE together: back to READY. from anything, with your program kept). F8 runs or pauses, F7 steps, F6 steps over a subroutine. In the editor, Ctrl+Enter runs, Ctrl+F finds, Ctrl+/ comments lines out. Vim keys are under the editor.

      Cassettes

      A cassette is a .unc.png: a picture of the tape with the program inside it, and the source if you include it. Save keeps it in your library in this browser. Export downloads it. Browse shows yours and the bundled ones. Drop .unc.png, .tap, .s or .bas files anywhere on the page to bring them in.

      The tape deck

      Put a cassette in the deck (Run in Browse, or Tape it for your project), type LOAD at READY. and press Play. Fast load loads as fast as the ROM can read. Without it, about 600 bytes a second, as on the real deck. To SAVE a BASIC program: Blank tape, type SAVE "NAME", press Rec. Eject it to keep it as a cassette.

      In the game

      To play it in the game: turn on My tapes in the game's pause menu (Settings, Assembler), then put the cassette in Documents/UNC 64/Cassettes (on Windows, C:\Users\<you>\Documents\UNC 64\Cassettes), or drop it on the game's window. It turns up in the shoebox on the desk: put it in the deck, LOAD, PLAY.
